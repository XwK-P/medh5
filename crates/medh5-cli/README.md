# medh5-cli

The native `medh5` command line: inspect, validate, verify, convert, curate and
pack MEDH5 samples.  It is a frontend over the [`medh5`](https://crates.io/crates/medh5)
format engine and produces the same output and exit codes as the command the
Python package installs.

```
cargo install medh5-cli
medh5 info case.medh5
```
